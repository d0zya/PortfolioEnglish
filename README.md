<h1>Neftecode (Chemistry Hackathon)</h1>
  
  <div align="center">
      <img src="https://github.com/d0zya/Portfolio/blob/main/hack_imgs/neftecode2026.png" alt="Image 2", width="50%">
  </div>
   <br>
   <strong>Problem:</strong>
   <p>
       Predicting the results of the Daimler oxidation test for multi-component lubricant formulations is challenging due to complex nonlinear interactions between components, variable formulation compositions, limited and incomplete data, and the need to account for the physicochemical nature of the processes; Therefore, there is a need to develop an interpretable and robust ML model capable of handling large numbers of components, accounting for their properties and experimental conditions, identifying intercomponent interactions, and accurately predicting oxidation rates and viscosity changes for new formulations, with the ability to reproducibly run the model and analyze influencing factors.
   </p>

<h1>Gaica - AI Gaming Arena</h1>
  
  <div align="center">
      <img src="https://github.com/d0zya/Portfolio/blob/main/hack_imgs/gaica.png" alt="Image 4", width="25%">
  </div>
   <br>
   <strong>Problem:</strong>
   <p>
       The hackathon challenge was to develop an intelligent game agent for a dynamic 2D environment in the style of a top-down shooter. The agent receives the complete state of the game world, including the positions of players, objects, weapons, and obstacles, and must make real-time decisions to control the character’s movement, aiming, and actions. Despite the environment being fully observable, the task is non-trivial due to the need to process the state and react to it at a high frequency, account for map geometry and visibility, and balance between aggressive and cautious behavior under conditions where the cost of error is high.
   </p>
